# Illager Invasion – unofficial 26.3 port

> [!NOTE]
> This is an **unofficial port** of [Illager Invasion](https://github.com/Fuzss/illager-invasion) by Fuzs to **Minecraft 26.3 (Fabric only)**.
> All credit for the mod goes to the original authors (Dricky, Safro, Zeckemith, Fuzs). It stays under the original MIT license.
>
> - Downloads for this port are on the [releases page](https://github.com/OctoMiku01/illager-invasion/releases).
> - Please report problems with this port in [this fork's issues](https://github.com/OctoMiku01/illager-invasion/issues), not to Fuzs.
> - Requires [Fabric API](https://modrinth.com/mod/fabric-api), [Puzzles Lib](https://modrinth.com/mod/puzzles-lib) and [Forge Config API Port](https://modrinth.com/mod/forge-config-api-port) for 26.3.
> - The port lives on the `port/26.3` branch.

A Minecraft mod. Downloads of the official versions can be found on [CurseForge](https://www.curseforge.com/members/fuzs_/projects) and [Modrinth](https://modrinth.com/user/Fuzs).
